# Reporting a security issue

Use this repository's **Security → Report a vulnerability** feature for a private report. Do not include access tokens, desktop account files, conversation history, or private contact identifiers in public issues.

This early release uses internal desktop interfaces and the current Windows user's Grok Bot login. Local contact configuration, queue contents and logs are private runtime data. The local HTTP panel binds to loopback and is not intended to be exposed on a network.

Only the latest prerelease is maintained. There is no response-time guarantee. Include the app versions, a minimal reproduction with fictional contacts, and the impact you observed. See [privacy documentation](docs/PRIVACY.md) for the data flow.
